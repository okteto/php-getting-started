# Getting Started with Okteto and PHP

This sample shows how to build, deploy, test, and develop a PHP application on Kubernetes with [Okteto](https://www.okteto.com). Okteto builds its application and development images from the `Dockerfile`, runs its unit tests in a Test Container, and replaces it with a Development Container that has hot reload and a debugger.

Follow the [Getting Started with Okteto and PHP](https://www.okteto.com/docs/development/containers/php/) guide.
